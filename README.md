# Which Home?
An audiovisual installation exploring memory and migration through data-driven visuals and sound.
## Demo  
https://www.youtube.com/watch?v=wHsIKdA9oV4
## What it is
- GAN trained on image datasets from Bucharest and London to generate contrasting visual environments  
- Sound compositions generated from field recordings taken in both cities  
- Audio features (frequency + amplitude) extracted and mapped to MIDI structures  
- Installed as a physical exhibition piece combining generated visuals and sound  

The project explores the degradation of an immigrant's memories over time, as Bucharest slowly blurs and London comes into focus, the installation captures the feeling of losing one home while gaining another.

## Tech
Python, PyTorch, NumPy, pydub, MIDIUtil, GANs, audio feature extraction

## Process
- Collected and processed image and audio data from both cities  
- Trained a GAN model to generate visuals based on location-specific datasets  
- Extracted audio features and translated them into musical structures  
- Built and installed the final audiovisual system
